# FAQ Review — ActionApps Documentation Consolidation

**Source:** https://actionapps.org/faq/ (147 entries, last major update ~2011)
**Purpose:** User reviews each entry → marks status → guides new doc writing

## How to Review

For each entry, mark one status in the **Status** column:

- **OK** — Content is still accurate, integrate into target doc
- **UPDATE** — Core concept valid but details outdated (PHP3 refs, old functions, etc.)
- **OUTDATED** — No longer relevant, skip
- **PRIORITY** — Important, write/integrate early

Add notes in the **Notes** column if needed.

- replace php3 with php
- check the examples in the code if appropriate
- check the links and use only if exists (or you are able to find relevant in other place)
- use better english,
- APC is no more involved, so less APC mentions for current services
- Talk more about ActionApps not APC AA
- before write the text, also check CHANGES file and SVN log, where all the features are documented on commit
- all SSI - like
  
      < !--#include...
  
  is outdated
- do not mention aa.ecn.cz/apc-aa as example site - use general example.org/apc-aa
- do not mention, that the feature is "confusing" or buggy (often in Mitras articles) - it is probably not true in modern AA
